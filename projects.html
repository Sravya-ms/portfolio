FoodLoop AI – Smart Food Redistribution Platform

A full-stack web platform that connects verified food donors (campus messes, caterers, banquet halls) with orphanages and old-age homes before surplus food goes to waste. Recipients place requests against live batches, and a request-acceptance workflow prevents overbooking across concurrent, partial-quantity reservations.

  • AI conversational assistant and demand-prediction module powered by the Google Gemini API, with role-based authorization so the assistant only sees each user's permitted data.
  • Verification-first access control with separate donor and recipient logins, real-time in-app chat triggered when a request is accepted, and an auto-expiring, time-bound donation lifecycle.
  • Deployed on Render with CI-linked builds and environment-based secrets management; builds, server startup, and API responses were validated end to end before release.

Technologies:
React/Vite • Node.js/Express • TypeScript • Google Gemini API • Render

AI Startup Idea Validator

Built during my Infosys Springboard AI internship: a multi-agent platform that evaluates startup ideas through market research, competitor analysis, SWOT analysis, MVP recommendations, and go-to-market strategy generation. Specialized agents built with the Deep Agents framework and DuckDuckGo Search share context and intermediate results through a centralized shared-state architecture, and an AI-powered conversational advisor generates validation reports and interactive recommendations.

Technologies:
Python • Deep Agents • DuckDuckGo Search • Streamlit • FastAPI • PostgreSQL • Docker
